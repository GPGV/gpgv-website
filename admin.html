🌐 Publish LIVE — one click, everyone sees it

Edit any page (click ✎ Edit page), then come back here and hit Publish LIVE. Your changes go to the GPGV server and every visitor on gpgv.ca sees them instantly — no files, no uploads.

📇 Contacts & signups — everyone who reached out, from every page

Every contact form, club application, and newsletter signup across gpgv.ca lands here and texts you instantly. This is your live contact database.

How it works

• Edit page opens it with a blue edit bar — click any headline, paragraph, price, or link text to change it. Double-click a link to change where it points.
• Edits auto-save to your browser and preview live.
• Export bundles every change into one gpgv-content.json. Drop that file in the site folder to publish for all visitors.
• Reset page (in the edit bar) undoes a page's changes.
